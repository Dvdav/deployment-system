# DS-006.1 — Basic Deployment Planning
**Статус:** архитектурные требования утверждены; реализационные детали открыты. **Зависимости:** ReleaseManifest/Environment/Targets/Profiles.

## Назначение
Построить предварительный план для выбранного READY Release (его ACTIVE ReleaseManifest) и Environment, не выполняя внешних jobs.

## Правила
- Входные данные: точный artifact asset из Manifest, EnvironmentServer и ComponentDeploymentTarget, DeploymentProfile по (Component, Environment, Operation), связанный ExecutionDefinition/branch, принятый параметрический контракт и overrides/defaults.
- План показывает операции на уровне Component + Environment + Server, порядок и использованные версии/targets/профили.
- STOP, START, VALIDATE необязательны; DEPLOY выполняется только когда обновление действительно нужно (см. DS-006.4). VALIDATE создаётся непосредственно после START, либо после DEPLOY, если DEPLOY самостоятельно переводит компонент в рабочее состояние и отдельного START нет.
- Если нужного профиля/target/job, обязательного параметра или принятого контракта нет, запуск блокируется понятной ошибкой. Перед стартом повторно проверяются внешние execution contracts; изменения — diff/warning/acknowledgment или block по типу.
- PLAN не меняет Manifest, не выбирает произвольную другую версию, не хранит секреты в plaintext snapshot.
- Для выбранного компонента без необходимых изменений операции обновления не создаются, кроме воздействия зависимостей или явного Force Redeploy.
- Первая версия планировщика — последовательное выполнение независимых компонентов, ALL_AT_ONCE по тем серверам компонента, которым нужны шаги.

## Приёмочные сценарии (проект тестов)
- Три target сервера, валидные profiles: план содержит соответствующие индивидуальные шаги.
- START отсутствует, но DEPLOY приводит компонент в рабочее состояние: DEPLOY → VALIDATE.
- Несовместимый контракт или отсутствующий обязательный профиль: план остаётся незапускаемым с объяснением.
- Версия/asset в Manifest и в плане идентичны; модификация версии через план невозможна.

## Открыто до реализации
Явный контракт профиля «DEPLOY запускает сервис»; формат snapshot и генерация защищённых параметров, связывающих артефакт и сервер с job-параметрами. Реальный запуск — DS-007.
